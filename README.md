# Alafia Agriculture Website

Static single-page website starter for Alafia Agriculture.

Download the complete source package from `alafia-agriculture-website-starter.zip` in this repository and extract it to work with the site files.

The package includes the HTML, CSS, JavaScript, editable JSON content, brand assets, and setup instructions.

Before launch, replace stock imagery with genuine farm photographs and verify contact details, product information, and delivery arrangements.
