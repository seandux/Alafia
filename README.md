# Alafia Agriculture Website

Responsive single-page static website for Alafia Agriculture.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — product cards and mobile navigation
- `assets/content.json` — editable business details and announcement settings

## Local preview
Run a local static server from this directory, for example `npx serve .`, or use VS Code Live Server.

## Edit business information
Update `assets/content.json` when the business phone numbers, emails, location, tagline, or announcement changes. Product cards are currently maintained in `script.js`.

## Before launch
1. Replace demonstration photography with genuine Alafia farm photographs.
2. Add the approved original Alafia logo artwork to the repository and update the header/footer to use it.
3. Verify both email addresses and the written farm location.
4. Confirm product availability, packaging, quantities, and delivery arrangements.
5. Confirm all public business claims with the farm.

## Hosting
This is a static site and can be deployed using GitHub Pages, Netlify, Cloudflare Pages, or Vercel. No database or backend is required for this version.
